## 24/7 Shop Interior Redesign

Redesigned 24/7 shop interior which changes the interior of all 24/7 stores across the map. Few quality of life changes, and a modern refresh.

Changes:
- modernised some of the colour scheme
- removed some of the branding off the windows to make it look less 'busy'
- removed dirt and spills from the floor
- moved a few items in the office area (for RP purposes)
- removed fan and chair from behind the counter (often got in the way)
